# Asset replacement prompts

The assets listed below are fictional, original SVG illustrations. Scent Vault's PNG files are screenshots of the real client website and are not generated placeholders. These prompts are starting points for creating licensed replacement artwork. Keep filenames and dimensions when replacing SVGs; for PNG or WebP, update the referenced extension in code. Never present invented projects as real client work.
